# Changelog

All notable changes to this app. Versions match the
[GitHub releases](https://github.com/dhavall08/mac-clock-calendar-widget/releases).

## [1.1.1] - 2026-11-23

### Fixed

- Widgets can be moved again. Drag anywhere on a widget to move it. Buttons
  inside the widget, like the calendar's month arrows, still work as before.
- Resizing with the corner grip is smooth now. The widget used to jitter and
  jump while you dragged.
- A locked widget can be unlocked from the widget itself. Hover just above
  its top edge and the toolbar appears with the lock button. Before, you had
  to unlock it from Settings. Clicks on the rest of a locked widget still pass
  through to whatever is behind it.
- A locked widget hides its resize grip and can't be dragged.
